## 🌟 จุดเด่นและคุณสมบัติสำคัญ

1. **Zero-API & Zero-Setup 100% (ไม่ต้องใช้ API Key)**
   - ผู้เรียนทุกคนเข้าใช้งานได้ทันทีโดยไม่ต้องขอ, สมัคร หรือกรอก API Key ใดๆ
   - ปลอดภัยตามมาตรฐาน PDPA และระเบียบความปลอดภัยสารสนเทศธนาคาร

2. **Mobile-First 1-Tap Copy (ออกแบบเพื่อสมาร์ตโฟน)**
   - เมนูเลือกกลุ่มงานแบบชิป (Pills) แตะสลับง่ายด้วยมือเดียว
   - ปุ่มกดขนาดใหญ่ (Touch Target ≥ 48px) พร้อมระบบคัดลอกแบบ 1 สัมผัส (1-Tap Copy)
   - ลิงก์ตรง **"🚀 เปิด Gemini"** สำหรับสลับไปวางคำสั่งใน Google Gemini ได้ทันที

3. **อัตลักษณ์องค์กรทางการ ธ.ก.ส. (Official BAAC Corporate Identity - CI)**
   - ตราสัญลักษณ์ทางการ ธ.ก.ส. (พร้อมระบบสำรองภาพแบบ Offline Base64 Data URI)
   - โทนสีเขียวมรกตและทองรวงข้าวตามมาตรฐานเว็บไซต์หลัก ([www.baac.or.th](https://www.baac.or.th))
   - แถบข้อมูลสถาบัน สายด่วน Contact Center 1593 / 0 2555 0555
   - ปุ่มปรับขนาดตัวอักษรเพื่อการเข้าถึง (Accessibility `A-` / `A` / `A+`)

4. **ครอบคลุม 11 กลุ่มงาน สำนักธุรกรรมการเงิน ครบทุกหมวดงาน (38 แม่แบบ)**
   - หมวดร่างเอกสารทางการและบันทึกข้อความ ธ.ก.ส. ครบ 11 กลุ่มงาน
   - หมวดวิเคราะห์ข้อมูลและสรุปสถิติ ครบ 11 กลุ่มงาน
   - หมวดตรวจสอบและกระทบยอดเงินโอน/บัญชี 9 กลุ่มงาน
   - ระบบตัวกรองอัจฉริยะ ซ่อนหมวดที่ไม่มีข้อมูลอัตโนมัติ ไม่พบหน้าจอว่าง

5. **ศูนย์สร้างมินิแอพด้วย Gemini Canvas (11 มินิแอพ)**
   - กรอบความคิด **APP-CRAFT Framework 5 ขั้นตอน** สำหรับพนักงานฝ่ายปฏิบัติการ
   - Prompt สำเร็จรูปสำหรับสั่งให้ Gemini Canvas เขียนโค้ดสร้าง Interactive Dashboard / Mini-App ประจำกลุ่มงาน
   - ระบบตัวจำลองแอปพลิเคชัน (Live Interactive Canvas Simulator) ในตัว

6. **ระบบ QR Code ห้องเรียนออฟไลน์ (Classroom QR Code Access)**
   - รองรับผู้เรียน 150 คน สแกนเข้าใช้งานพร้อมกัน
   - ทำงานแบบออฟไลน์ 100% ตามมาตรฐาน ISO/IEC 18004
   - มีโหมดคอนทราสต์สูง (High Contrast) สำหรับฉายขึ้นจอโปรเจกเตอร์หน้าห้องเรียน

## 🚀 วิธีการเปิดใช้งานระบบ

### ทางเลือกที่ 1: เปิดใช้งานผ่านเครือข่าย Wi-Fi ในห้องเรียน (Local LAN Server)
```bash
python3 run_server.py
```
- ระบบจะตรวจจับ IP Address ของเครื่องวิทยากรในวง Wi-Fi อัตโนมัติ (เช่น `http://192.168.1.xxx:8000`)
- เปิดหน้าต่างเบราว์เซอร์อัตโนมัติ พร้อมสร้าง QR Code ให้ผู้เรียน 150 คนสแกนเข้าใช้งาน

### ทางเลือกที่ 2: เผยแพร่ผ่าน GitHub Pages (แนะนำสำหรับการใช้งานออนไลน์)
1. นำโค้ดขึ้น GitHub Repository
2. ไปที่ **Settings** > **Pages**
3. เลือก Source เป็น `main` สาขา (Branch) และโฟลเดอร์ `/(root)` แล้วกด **Save**
4. ระบบจะเปิด URL ออนไลน์ให้เข้าใช้งานได้ทั่วโลกทันที (เช่น `https://<username>.github.io/<repo-name>/`)
